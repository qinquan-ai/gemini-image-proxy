## 🔍 影响因素分析

根据基线测试（`gemini_image_baseline`），生成成功率受多因素影响：

### 1. Cookie 新鲜度 ⭐⭐⭐⭐⭐
- **关键因素**：Cookie 过期会导致退回到未登录状态（显示 "Sign in"）
- **建议**：每次使用前运行 `update_cookies.py` 刷新
- **有效期**：通常 24-48 小时（视 Google 账户安全策略）

### 2. 代理地区 ⭐⭐⭐⭐⭐
- **完全屏蔽**：CN/RU/IR/KP（返回 403 或功能不可用）
- **图像受限**：JP（可能降级为 Flash-Lite）
- **推荐地区**：US/CA/AU/SG/IN/KR
- **代理要求**：必须覆盖浏览器流量（系统代理可能无效）

### 3. 时段负载 ⭐⭐⭐
- **凌晨**：成功率最高，排队时间短
- **白天/下午**：可能遇到额度限制或排队
- **不确定性**：现有数据不足以证明时段是唯一决定因素

### 4. 账户额度 ⭐⭐⭐
- 单账户可能有每日/每小时生成限制
- 短时间内连续请求可能触发冷却
- 建议使用多账号轮换策略

## 🎯 使用建议

### 生产环境部署
1. **优先使用凌晨时段**（UTC+8 01:00-04:00）部署关键任务
2. **配置多账号池**：至少 3-5 个账户轮换
3. **实时监控 Cookie 状态**：检测到 "Sign in" 立即刷新
4. **设置合理超时**：45-180 秒（基线测试约 38 秒）
5. **地区选择**：优先美国/新加坡节点

### 调试失败问题
如果生成失败，按以下顺序排查：
1. ✅ Cookie 是否有效？（运行 `update_cookies.py --visible` 验证登录状态）
2. ✅ 代理是否生效？（检查浏览器实际 IP 地址）
3. ✅ 代理地区是否受限？（参考地区检测规则）
4. ✅ 是否在高峰时段？（尝试切换到凌晨）
5. ✅ 账户是否触发限制？（切换到其他账号）
